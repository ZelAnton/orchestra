# Ревью обработки отказов Claude API

Область: классификация служебных ошибок Claude, остановка без восстановления,
сохранение фазы/сессии и документация оператора. Ревью выполнил Codex, внесший
изменения. Три чистых прохода относятся к одному снимку пяти файлов; контрольные
суммы сверены после завершения. Отчёт добавлен после проверки снимка.

## Диагностика

В read-only протоколе Interlink для invocation
`d6af7d912fe945f0bcae9d5ddf733214` обнаружено исходное событие:
`assistant`, `message.model=<synthetic>`, `is_api_error_message=true`,
`error=oauth_org_not_allowed`. CLI 2.1.268, `apiKeySource=none`.
Проверка модели ошибочно классифицировала это событие как `model-rerouted`.
Вызов не сформировал завершённого отчёта ревью.

Исходное событие воспроизведено через транспорт с имитацией процесса в
одноразовом репозитории: результат — `claude-access-denied`. Настоящий провайдер
не запускался. Interlink, его runtime, учётные данные и разрешения не изменялись.

Оператор уточнил, что подписка личная Pro/Max. Документация дополнена маршрутом
в поддержку для такого случая. По [официальному описанию ошибки](https://code.claude.com/docs/en/errors#your-organization-has-disabled-claude-subscription-access),
запрет действует на сервере и не снимается повторным входом тем же аккаунтом
или локальными флагами. Изменение Orchestra исправляет диагностику и маршрутизацию;
восстановление подписочного доступа остаётся внешним требованием.

## Чистый проход 1 — классификация

Проверены порядок проверки init/assistant/result, точные признаки служебного
API-события, совпадение сессии, сохранение конкретного кода и ограничение деталей.
Обычный ответ другой модели остаётся запрещённым; упоминание ошибки в тексте
правильной модели не считается отказом API. Служебный отказ до init завершается
ошибкой, не выдавая успешного отчёта. Проверены выход исключения и закрытие процесса.
Замечаний и исправлений нет. Чистых подряд: 1.

## Чистый проход 2 — состояние и продолжение

Проверены остановка без healer, отсутствие завершённого отчёта и нового review
credit, сохранение Astra, сброс прерванной серии Claude и сохранение её сессии.
После восстановления доступа требуются два завершённых прохода Claude.
Проверены неизменные барьеры дрейфа файлов и незавершённой доставки сообщений:
отказ API не позволяет обойти повторное ревью или потерять адресованное сообщение.
Замечаний и исправлений нет. Чистых подряд: 2.

## Чистый проход 3 — интеграция и инструкции

Повторно проверены весь diff и строгая фиксация модели, маршрут старого blocker
через --retry, отсутствие переключения аккаунта/ключа/модели, загрузка существующих
модулей через cc-sync и инструкция для личной подписки. Проверены граница
read-only диагностики Interlink, контрольные суммы и результаты общего набора.
Замечаний и исправлений нет. Чистых подряд: 3.
