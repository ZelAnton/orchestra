# cc-focus: ревью перед публикацией

Дата: 2026-09-14.

Проверен накопленный cc-focus: отдельный последовательный цикл, постоянные
сессии ролей, терминал и статус, доставка сообщений, восстановление, согласование
контекста, публикация нескольких репозиториев и установка через cc-sync.
В публикацию входят только cc-focus и его зависимости. Изменения cc-config,
локальные настройки Claude и Python-кэш исключены. Общие README, knowledge и
environment-variables проверены в том составе, который включён в commit.

## Исправления

- Запретить `reconcile --plan-out` создавать служебный `.work/control_state.json`.
  Используется общий список runtime-путей; регрессия проверяет отказ без записи.
- Отклонять пустые и состоящие из пробелов элементы `evidence`, чтобы такой отчёт
  не получал зачёт ревью. Сохранена совместимость непроверяющих ролей с пустым
  списком; провайдерная схема также требует непустых строк.
- Перед завершением CI одиночного репозитория повторно проверять защищённые файлы
  и staging. Регрессия подтверждает сохранение индекса и текущей итерации при
  внешнем изменении staging; архив следующего перехода не создаётся.
- Сохранять исходный текст отказа Claude вместе с `oauth_org_not_allowed`.
  Диагностика предлагает проверить активный аккаунт и подписку/оплату, а для
  управляемого доступа — обратиться к администратору. Отказ не получает зачёт
  ревью и не меняет сессию или настройки доступа.

## Два чистых прохода

Оба прохода выполнены Codex самостоятельно, без делегирования другому агенту.
Это последовательное self-review, а не два независимых ревьюера.

1. После исправлений проверены протокол отчётов, границы ролей, восстановление,
   смена фаз, сохранение защищённой работы, публикация и CI. Новых замечаний нет.
2. Повторно проверены переходы при ошибках, привязка согласования к снимку,
   учёт результатов, терминал, зависимости launchers и точный состав публикации
   без cc-config. Новых замечаний нет; код после первого чистого прохода не менялся.

## Проверки

Проверки повторены в отдельном checkout, содержащем точный будущий состав
cc-focus поверх прежнего HEAD, без незакоммиченных изменений cc-config:

- `pwsh -NoProfile -File tests/launchers/run-all.ps1`: 12/12 наборов прошли,
  незавершённых дочерних процессов нет. На Linux пропущены 18 Windows-only наборов.
- Python внутри focus-набора: 148 workflow, 56 terminal, 17 status и 43 project
  теста; всего 264, из них 259 прошли, 5 пропущены по условиям среды.
- POSIX launcher tests, `shellcheck -x launchers/cc-focus.sh`, PowerShell lint
  и проверка согласованности — успешно.
- Генерация канонических ролей не изменила производные файлы. Проверки Python
  syntax, UTF-8/LF и CRLF для `.cmd`, а также `git diff --cached --check` — успешно.
- Все 48 файлов исходного состава публикации побайтово сверены с проверенным
  checkout. Этот отчёт добавлен отдельно после завершения проверок.
- Установленные focus-модули сверены с исходниками после cc-sync; содержимое
  установленных cc-config и настроек доступа сохранено.

Провайдеры моделей не запускались. Orbit и Interlink не изменялись. Локальные
проверки не являются результатом будущего GitHub CI или проверкой Windows.
