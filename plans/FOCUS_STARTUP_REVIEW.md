# Ревью диагностики запуска cc-focus

Дата: 2026-09-13. Область: проверка Git-каталога до открытия терминального
интерфейса, сообщения об отказе и описание поддерживаемой структуры проекта.
Ревью выполнил тот же Codex, который внёс исправление; независимого reviewer нет.
Три последовательных чистых прохода относятся к одному снимку пяти файлов:
`tools/cc_focus.py`, `tools/cycle_state.py`, `tests/test_focus_terminal.py`,
`docs/sequential-cycle.md`, `knowledge.md`. Между проходами файлы не менялись.

## Причина

Read-only диагностика Orbit показала: родительский каталог не является
Git-репозиторием; Core, Root и Specification — отдельные colocated Jujutsu/Git
репозитории с detached HEAD. Handoff и правила проекта подтверждают эту структуру.
В Orbit нет `.work/cycle`: запуск остановился до владения циклом и вызова модели.
Текущий профиль требует один существующий Git checkout на main. Параллельный
цикл Interlink не является причиной этого отказа.

Старый интерфейс открывался до проверки репозитория и после ошибки оставался
в ожидании команды со статусом `starting`. Регрессия на настоящем POSIX PTY
воспроизвела ожидание в режимах auto/on и недостаточную диагностику detached HEAD.
После переноса проверки ошибка остаётся в shell scrollback; код выхода — 3.
Orbit, Interlink, их checkout и runtime не изменялись. Поддержка нескольких
репозиториев и detached Jujutsu в этот профиль не добавлена.

## Проход 1 — полный scope, акцент на запуск

Проверены порядок разбора аргументов, Store, Git preflight, открытия UI,
повторной проверки при входе во владение и создание runtime-артефактов.
Проверены девять PTY-сценариев: отсутствие репозитория, вложенный каталог,
detached HEAD, каждый в auto/on/off. Ошибка видима без alternate screen,
процесс завершается без провайдера и без `.work/cycle`.
Замечаний и исправлений нет. Чистых подряд: 1.

## Проход 2 — полный scope, акцент на владение и продолжение

Повторно проверен весь diff, local lock, lease, Control и interactive resume.
В одноразовых репозиториях проверены одновременные локальные блокировки двух
разных корней, отказ повторному владельцу того же корня, допуск main,
отказ feature-ветке и linked worktree. Команды status/messages работают
вне Git без модели и без создания `.work`. Проверки cleanup и сохранённых
сессий остаются на прежнем пути; handoff не меняет корень или полномочия.
Замечаний и исправлений нет. Чистых подряд: 2.

## Проход 3 — полный scope, акцент на совместимость и доказательства

Снова проверены оба runtime-файла, PTY fixture, документация, обработка
ошибок Git и отсутствие переключений checkout/веток. Сверены контрольные
суммы всех пяти файлов, результаты общего прогона и отсутствие drift
сгенерированных ролей. Документация не обещает поддержку структуры Orbit.
Замечаний и исправлений нет. Чистых подряд: 3.

- Новая PTY-регрессия до исправления: шесть ожиданий до timeout и два отказа
  проверки текста ошибки. После исправления все девять вариантов прошли.
- `pwsh -NoProfile -File tests/launchers/run-all.ps1`: 12/12 наборов,
  394773 мс, survivors=0. На Linux пропущены 18 Windows-only наборов.
- В общем прогоне: 139 workflow-тестов (4 пропуска), 55 тестов ввода/терминала,
  17 тестов статуса; все выполненные проверки успешны.
- Python syntax, UTF-8 без BOM, пробелы новых строк, `git diff --check` и
  отсутствие изменений сгенерированных ролей проверены.
- Снимок: `.work/focus-startup-review-snapshot.json`; общий результат:
  `.work/focus-startup-suite-summary.json`; лог: `.work/focus-startup-suite.log`.

Установленное зеркало не обновлялось; для установки исправления оператор
выполняет `cc-sync` из checkout Orchestra. Commit и push не выполнялись.
